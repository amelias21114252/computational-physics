# Computational Physics Homework 1

This repository contains the Python source and figures for Homework 1.

## Files
- `homework1.py`: complete reproducible solution for Problems 1-3.
- `lcdm_z0.matter_pk`: tabulated matter power spectrum supplied with the assignment.
- `figures/`: figures generated by the script.
- `results/`: CSV tables generated by the script.
- `homework1_writeup.tex`: LaTeX writeup.

## Run
```bash
python -m pip install numpy scipy matplotlib
python homework1.py
```

The script uses explicit `numpy.float32` arithmetic for the single-precision parts of Problems 1 and 2. Problem 3 uses SciPy cubic-spline interpolation and oscillatory quadrature.
